使用技术要求:
产品性能:
丙森锌属于二硫代氨基甲酸酯类杀菌剂，对蔬菜和果树的卵菌纲病害、叶斑类病害都有较好保护效果。本品仅用于加工杀菌剂制剂，不可直接用于农作物和其它场所。
注意事项：
1. 在操作时，包括开启装有本品的容器，倾倒和收集本品时，应穿防护服、戴防尘口罩、橡胶手套及护目镜，严禁吸烟和饮食，避免接触皮肤和眼睛；
2. 每次操作结束后，用肥皂洗净全身及防护用具； 
3. 勿将含有本剂的固体和液体倒入河流、湖泊和其它水源中；
4. 用过后的空包装禁止再次使用。本品的包装材料和废弃物，以有毒废弃物，送到相关废弃物处理单位进行相应处理；
5. 若所贮存环境着火，在戴有呼吸面具的情况下，穿戴防护服，用二氧化碳、泡沫、沙子和灭火粉剂等物质进行扑灭；
6. 本品若发生泄漏，应在穿戴防护服的情况下将泄漏的产品收集起来，装在密闭的容器中，送到相关废弃物处理单位进行相应处理。
中毒急救措施：
1. 基本建议：马上将患者移出污染区，并脱掉被污染衣物，并妥善处置；
2. 如不慎接触皮肤，立即脱掉防护服，并立即用肥皂和大量清水冲洗；
3. 如不慎接触眼睛，立即摘除受污染的眼镜，并用大量清水冲洗眼睛和眼睑；
4. 如不慎误食，请马上就医； 
5. 对于误食者需洗胃，使用木炭（碳水化合物药品）和硫酸钠；
6. 如发生中毒或化学事故请拨打国家化学事故应急响应专线0532-83889090。
储存和运输方法：
1. 本品应以拧紧密封的原包装贮存于阴凉、干燥和通风处，避免阳光直射，远离火源；
2. 避免与酸性物质接触；
3. 勿与食品、饮料、饲料、种子和肥料等其它商品同贮同运；
4. 加锁保存，避免儿童等无关人员接触；
5. 运输时应注意防水防潮，避免雨淋；搬运时轻搬轻放，不可倒置。
